# MortherOfTheKing_v03

## Branches
Branches will be created for each new feature being developed. Once a feature is complete, the branch will be merged into a test-copy of the main branch and manually checked that nothing has broken. Then, the test-copy-merged branch will be merged with the main branch.
The naming conventions for branches will be as follows:
- DeveloperName_FeatureName

## Commmits
Regular and documented commits are expected of all developers working on this project.
The naming conventions for commits will be as follows:
- Slug: KeyWords
The key words, or slugs, indicate what kind of change has been made. Here is a list:
- Feat: commits adding, adjusting, or removing features
- Fix: commits fixing a bug of a preceeded feat commit
- Refactor: commits rewriting or restructuring code without altering behaviour outcomes
- Style: commits only affecting visual look of code
- Chore: commits that are changing technical things such as initial commits, or modification of .gitignore
- Merge: Old Branch to New Branch
